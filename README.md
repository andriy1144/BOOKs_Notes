# 📘 Books Notes

A lightweight and easy-to-use web application for storing books you've read and the notes or thoughts you’ve written about them.  
Perfect for readers who want to keep track of their reading journey and reflect on each book.

## 🚀 Features

- 📚 Add and manage a list of books you've read  
- 📝 Write personal notes or summaries for each book  
- 🔍 Search through your collection  
- 💾 Data persistence using server-side database

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript (Node.js)**

## 📚 Libraries & Frameworks

- [Express.js](https://expressjs.com/) — Web framework for Node.js  
- [EJS](https://ejs.co/) — Templating engine  
- [body-parser](https://www.npmjs.com/package/body-parser) — Middleware for handling request bodies  
- [dotenv](https://www.npmjs.com/package/dotenv) — Loads environment variables from `.env`
- [pg](https://www.npmjs.com/package/pg) — Non-blocking PostgreSQL client for Node.js.

## 💡 How to Use

1. **Clone the repository**:
   ```
   bash
   
   git clone https://github.com/andriy1144/BOOKs_Notes.git
   
   cd BOOKs_Notes
   ```
2. **Install dependencies**:
   ```
   npm install
   ```

3. **Set up environment variables**:
   ```
   DATABASE_USER = <db_user>
   DATABASE_NAME = <db_name>
   DATABASE_PASSWORD = <db_password>
   DATABASE_PORT = <db_port>
   DATABASE_HOST = <db_host>

   ```
4. **Start the server**:
   ```
   node src/index.js
   ```
5. **Visit the app in your browser**: 
   ```
   http://localhost:3000
   ```
